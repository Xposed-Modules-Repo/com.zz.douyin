# 抖仙人

<img src="https://raw.githubusercontent.com/1zzzzzlll/douyim/master/docs/douxianren-icon.png" alt="抖仙人图标" width="160">

面向抖音 Android 客户端的 LSPosed Modern API 102 纯净播放模块。

## 功能

- 功能总开关：关闭后恢复抖音原有界面和操作，停止模块功能，保留各子开关配置。
- 沉浸式播放独立开关：可单独关闭纯净播放，继续使用内容过滤、双击拦截和暂停下载。
- 可选禁用屏幕双击，拦截视频双击点赞和爱心动画，保留单击、滑动与侧边长按。
- 可选“双击打开评论区”：双击画面直接展开抖音原生评论区，不再触发点赞与爱心动画。
- 沉浸播放时屏蔽隐藏按钮及其子控件的触摸响应；点击原按钮区域会暂停并恢复完整界面。
- 保留侧面长按的原生快进／快退手势及上下滑动切换视频，屏蔽中间长按菜单。
- 修复长按结束后立即点击时，暂停却未恢复界面的问题。

- 播放视频时隐藏视频画面以外的抖音界面和系统栏。
- 可在模块设置页开启播放弹幕，纯净播放时保留抖音原生弹幕（40.8 起按整层保留 Compose／Functor／Canvas 各渲染层）。
- 滑动切换视频时持续隐藏其他控件，避免界面闪烁。
- 暂停视频时立即恢复完整界面和视频页原始布局，避免介绍被底部菜单栏遮挡；继续播放后再次进入纯净模式。
- 暂停后在右侧操作栏顶部显示下载按钮，可选择“视频（无水印 MP4）”或“音频（MP3）”，保存到系统 `Download` 目录。
- 在模块设置页分别配置是否跳过广告、图文、直播和普通视频。
- 支持按关键词匹配普通视频的标题或介绍，命中后自动切换到下一条；关键词忽略英文大小写，
  可使用换行、逗号或分号分隔。
- 默认跳过广告、图文和直播，保留普通视频；关键词默认为空。

届时需要重新适配。

## 安装与使用

1. 在 LSPosed 模块仓库中下载并安装“抖仙人”。
2. 在 LSPosed 中启用模块并勾选默认作用域“抖音”。
3. 强制停止后重新打开抖音。
4. 正常播放时自动进入纯净模式；可选择显示弹幕，暂停后恢复界面并显示下载按钮。
5. 打开“抖仙人”应用，可修改功能总开关、沉浸式播放、禁用屏幕双击、双击打开评论区、播放弹幕、内容类型开关和视频关键词；设置会同步到抖音进程。
6. 总开关和沉浸式播放默认开启，禁用屏幕双击默认关闭。暂停后点击下载，可选择视频或 MP3 音频；音频从当前视频音轨提取并转码。

从 1.4.1 起模块包名调整为 `com.zz.douyin`。新包会与旧包名版本并存，请在升级后重新启用
`com.zz.douyin` 并确认抖音作用域。
